# Python_Boiler
Bash script for creating a lightweight Python project boilerplate.

Running the script creates the following layout:
```
my_project/
├── pyproject.toml
├── requirements.txt
├── requirements-dev.txt
├── .gitignore
├── README.md
│
├── .venv/
│
├── src/
│   ├── __init__.py
│   └── main.py
│
└── tests/
    ├── __init__.py
    └── test_main.py
```
